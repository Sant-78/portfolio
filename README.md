# Santosh Kumar Pal — Portfolio

Single-page portfolio site (HTML, CSS, JavaScript).

**Live URL (after GitHub Pages setup):**  
https://sant-78.github.io/portfolio/

## Deploy on GitHub Pages (no Git install needed)

### Step 1 — Add your resume

Place your resume PDF in this folder as:

```
resume.pdf
```

The site will offer it for download as `Santosh_pal_resume.pdf`.

### Step 2 — Create GitHub repository

1. Open [github.com/new](https://github.com/new) and sign in as **Sant-78**
2. Repository name: **`portfolio`**
3. Visibility: **Public**
4. Do **not** add README, .gitignore, or license (files already exist locally)
5. Click **Create repository**

### Step 3 — Upload files

On the empty repo page, click **uploading an existing file** and upload:

- `index.html`
- `css/` folder (with `styles.css`)
- `js/` folder (with `main.js`)
- `resume.pdf`
- `.gitignore` (optional)
- `README.md` (optional)

Click **Commit changes**.

### Step 4 — Enable GitHub Pages

1. Repo → **Settings** → **Pages**
2. **Build and deployment** → Source: **Deploy from a branch**
3. Branch: **main** (or **master**), folder: **/ (root)**
4. Click **Save**

After 1–3 minutes, the site will be live at:

**https://sant-78.github.io/portfolio/**

Share this link with employers (resume, LinkedIn, email signature).
